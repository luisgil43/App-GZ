📋 Instrucciones para preparar el archivo

La plantilla utiliza cuatro columnas. La columna etapa es opcional: puedes dejarla completamente en blanco.

Columna Descripción Valores permitidos
name Nombre del requerimiento Texto obligatorio y sin duplicados
order Orden de presentación Número entero
mandatory Indica si la fotografía es obligatoria 1 = Sí / 0 = No
etapa Clasificación de la fotografía antes / durante / despues / vacío

Ejemplo de archivo

name order mandatory etapa
Foto general del sitio antes de intervención 0 1 antes
Foto durante instalación 1 1 durante
Foto después de intervención 2 1 despues
Foto adicional del sitio 3 0 Vacío
Importante:

No es obligatorio clasificar todas las fotografías. Si una fotografía no corresponde a Antes, Durante o Después, deja la columna etapa vacía.
